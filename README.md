# AstrBot 纸飞机插件 (Paper Plane)

纸飞机 —— 让 Bot 帮你在私聊里给指定的人传话。

## 📖 简介

**astrbot_plugin_paper_plane** 是一个专为 AstrBot 设计的私聊消息代发插件。
你可以通过自然语言告诉 Bot：“给张三发‘今天吃什么’”，Bot 会自动识别意图，提取目标用户，并以极具个性化的语气帮你把消息传达过去。

**核心定位：只在私聊场景响应，群聊完全静默。**

## ✨ 功能特性

- 💬 **纯私聊交互**：仅在私聊触发，不打扰群聊环境。
- 🎯 **双层意图识别**：内置正则匹配常见句式（零成本），复杂自然表达自动交由大模型判断。
- ✨ **AI 智能润色**：可选的 AI 润色功能，支持继承 AstrBot 当前人格，转述与反馈更生动自然。
- 🧠 **深度记忆库直连**：原生支持只读提取 `LivingMemory` 本地 SQLite 数据，解决跨群、改名导致的找不到人问题。
- 🚀 **多群临时会话兜底**：对方不是好友时，自动按配置顺序尝试通过多个群发起临时会话，确保送达。
- ⚡ **全局秒级缓存**：一键缓存好友与指定群成员，彻底告别接口卡顿与超时。
- 🛡️ **防误触机制**：内置代词黑名单与请求语境拦截，防止日常闲聊被误判为传话。

## 💡 使用示例

**私聊 Bot 发送：**

```text
给张三发"你在干什么"
告诉李四我晚点回
帮我跟王五说一声谢谢
```

**Bot 响应（开启 AI 润色后）：**

> 张三那边说：你在干什么呢喵？
> 好哒，话已经带给李四啦，放心喵~

## 📦 安装步骤

1. 将 `astrbot_plugin_paper_plane` 整个文件夹放入 AstrBot 的插件目录 `AstrBot/data/plugins/` 中。
2. 在 WebUI 的 **插件管理** 页面，找到“纸飞机”插件，点击 **重载插件**。
3. 根据下方“配置详解”填写必要项。

## ⚙️ 配置详解

### 1. 基础配置
| 配置项 | 默认值 | 说明 |
|---|---|---|
| `alias_map` | 空 | **好友别名映射**。格式：`名字:QQ号`。支持模糊匹配（配置了“张三”，发“给张”也能匹配）。 |
| `temp_session_group_ids` | 空 | **临时会话发起群号列表**。支持多个群号，用逗号或换行隔开。 |
| `cache_ttl` | 1800 | **用户与群成员缓存有效期（秒）**。填 0 表示每次请求都重新拉取。 |

### 2. 意图判断（正则 + AI）
| 配置项 | 默认值 | 说明 |
|---|---|---|
| `judge_regex_enable` | true | 启用正则预判。命中后直接抽取，不调用 AI。 |
| `judge_regex_patterns` | (默认内置) | 正则模式列表，需包含两个捕获组：(接收者) 和 (内容)。 |
| `judge_llm_enable` | true | 正则不命中时，使用 AI 判断意图。 |
| `judge_llm_provider_id` | 空 | 用于意图判断的 AI 模型。建议指定便宜的小模型。 |
| `judge_llm_system_prompt` | (内置) | 意图判断提示词，一般无需修改。 |

### 3. AI 智能润色
开启后，Bot 发送的转述和反馈将由 AI 生成，更具互动感。
| 配置项 | 默认值 | 说明 |
|---|---|---|
| `enable_llm_extension` | false | **总开关**。开启后转述和反馈交由 AI 生成。 |
| `use_persona_in_extension` | true | **使用当前人格**。继承当前会话的 AstrBot 人格。若关闭则用默认工具人语气。 |
| `prompt_mode_in_extension` | append | **提示词应用模式**。`append`（追加要求）或 `override`（完全替换）。 |
| `custom_system_prompt` | 空 | **自定义提示词**。留空跟随人格，填写后根据模式生效。 |

### 4. 记忆插件支持
| 配置项 | 默认值 | 说明 |
|---|---|---|
| `enable_memory_lookup` | false | 启用记忆插件别名查询，从历史发言中找寻目标用户。 |
| `memory_plugin_mode` | auto | 模式选择：`auto` / `livingmemory` / `mnemosyne` / `memory_companion` / `off`。 |

### 5. 其他
| 配置项 | 默认值 | 说明 |
|---|---|---|
| `simple_generate_template` | `{sender_name}说：{content}` | 未开启智能润色时的转述模板。 |
| `debug_mode` | false | 开启后日志会打印 AI 原始返回，便于排查。 |

## 🛡️ 写死的安全规则

为了保障体验，以下规则在代码中写死，不可配置：
1. **仅在私聊响应**：群聊中使用传话指令会被完全忽略。
2. **忽略 Bot 自身消息**：防止引发无限死循环。
3. **超长消息过滤**：超过 500 字的消息直接忽略。
4. **必定回复机制**：无论成功还是失败，必定给予发送者反馈。
5. **正则智能拦截**：自动过滤“你/我/他”等代词；自动拦截请求动作的语境。

## ❓ 常见问题 (FAQ)

**Q1：为什么对方不是好友时发不出去？**
A：QQ 机器人受平台限制，无法直接给非好友发送私聊。请确保满足以下条件：
1. 在 `temp_session_group_ids` 中配置了有效的群号。
2. 机器人与目标用户都在该群内。
3. 该群开启了“允许群成员发起临时会话”。

**Q2：LivingMemory 提示找不到数据库？**
A：插件默认从 `data/plugin_data/astrbot_plugin_livingmemory` 读取。请确保你安装了该插件，并且路径一致。

**Q3：为什么 AI 生成的反馈生硬？**
A：可以在 AstrBot 中为当前会话绑定一个活泼的「人格」，并确保开启了 `enable_llm_extension` 和 `use_persona_in_extension`。
